# 5.8 Glossário: Capítulo 5

{% include "../.gitbook/includes/estes-sao-os-termos-que-con....md" %}

<table data-full-width="true"><thead><tr><th>Termo</th><th>Definição (no contexto do Capítulo 5)</th></tr></thead><tbody><tr><td><strong>Salvar (no Git)</strong></td><td>Registrar um <strong>estado do projeto</strong> em um ponto do tempo, sem apagar o passado.</td></tr><tr><td><strong>Versão / estado do projeto</strong></td><td>“Foto” de como o projeto está em um instante específico (conjunto de arquivos + conteúdos).</td></tr><tr><td><strong>Checkpoint</strong></td><td>Analogia para entender o “salvar” do Git. Um ponto seguro para voltar depois.</td></tr><tr><td><strong>Working Directory</strong></td><td>Área onde você edita arquivos no seu computador. Onde o trabalho acontece.</td></tr><tr><td><strong>Staging Area</strong></td><td>Área de preparação. Onde você seleciona e organiza quais mudanças entram na próxima versão.</td></tr><tr><td><strong>Index</strong></td><td>Nome alternativo para a staging area.</td></tr><tr><td><strong>Repository (local)</strong></td><td>Área onde o Git guarda as versões registradas. Faz parte do repositório local no seu computador.</td></tr><tr><td><strong>Diretório <code>.git</code></strong></td><td>Pasta oculta onde o Git armazena metadados e o histórico do repositório.</td></tr><tr><td><strong>Rastreamento (tracking)</strong></td><td>A “decisão” de o Git acompanhar um arquivo. Presença na pasta não implica versionamento.</td></tr><tr><td><strong>Untracked</strong></td><td>Arquivo fora do controle do Git. Existe na pasta, mas o Git não acompanha mudanças nele.</td></tr><tr><td><strong>Tracked</strong></td><td>Arquivo sob controle do Git. O Git monitora mudanças e pode registrar novas versões dele.</td></tr><tr><td><strong>Ignored</strong></td><td>Arquivo explicitamente marcado para o Git ignorar (não rastrear nem avisar).</td></tr><tr><td><strong>Histórico</strong></td><td>Linha do tempo das versões registradas. Permite voltar, comparar e entender a evolução do projeto.</td></tr></tbody></table>

# 5.8 Glossário: Capítulo 5

{% include "../.gitbook/includes/estes-sao-os-termos-que-con....md" %}

| Termo                          | Definição (no contexto do Capítulo 5)                                                              |
| ------------------------------ | -------------------------------------------------------------------------------------------------- |
| **Salvar (no Git)**            | Registrar um **estado do projeto** em um ponto do tempo, sem apagar o passado.                     |
| **Versão / estado do projeto** | “Foto” de como o projeto está em um instante específico (conjunto de arquivos + conteúdos).        |
| **Checkpoint**                 | Analogia para entender o “salvar” do Git. Um ponto seguro para voltar depois.                      |
| **Working Directory**          | Área onde você edita arquivos no seu computador. Onde o trabalho acontece.                         |
| **Staging Area**               | Área de preparação. Onde você seleciona e organiza quais mudanças entram na próxima versão.        |
| **Index**                      | Nome alternativo para a staging area.                                                              |
| **Repository (local)**         | Área onde o Git guarda as versões registradas. Faz parte do repositório local no seu computador.   |
| **Diretório `.git`**           | Pasta oculta onde o Git armazena metadados e o histórico do repositório.                           |
| **Rastreamento (tracking)**    | A “decisão” de o Git acompanhar um arquivo. Presença na pasta não implica versionamento.           |
| **Untracked**                  | Arquivo fora do controle do Git. Existe na pasta, mas o Git não acompanha mudanças nele.           |
| **Tracked**                    | Arquivo sob controle do Git. O Git monitora mudanças e pode registrar novas versões dele.          |
| **Ignored**                    | Arquivo explicitamente marcado para o Git ignorar (não rastrear nem avisar).                       |
| **Histórico**                  | Linha do tempo das versões registradas. Permite voltar, comparar e entender a evolução do projeto. |

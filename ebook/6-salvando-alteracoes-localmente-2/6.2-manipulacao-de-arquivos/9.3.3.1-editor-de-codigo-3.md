# 6.2.4 Manipulando arquivos no Visual Studio Code

Agora que conhecemos os principais elementos da interface, é o momento de começar a interagir com o Visual Studio Code.

Nesta seção, exploraremos as ações mais básicas realizadas no editor. O objetivo não é aprender recursos avançados, mas desenvolver familiaridade com o ambiente e compreender como manipular arquivos dentro de um projeto.

Caso o editor ainda não esteja instalado em sua máquina, consulte a seção [Visual Studio Code](9.3.3.1-editor-de-codigo-1.md), onde apresentamos o processo de instalação.

A seguir, veremos um passo a passo que demonstra as interações fundamentais do VS Code.

## Passo a passo

{% stepper %}
{% step %}
### 1. Abrir o VS Code

<figure><img src="../../.gitbook/assets/0463.png" alt=""><figcaption><p>VS Code aberto</p></figcaption></figure>
{% endstep %}

{% step %}
### 2. Fechar a aba de “Bem-vindo”

Ao abrir o VS Code, ele pode mostrar a aba **Bem-vindo**. Ela serve como um atalho para ações comuns, como **abrir uma pasta**, criar um arquivo, instalar extensões e ver atalhos. Como neste capítulo vamos trabalhar direto com o projeto, você pode fechá-la sem medo.

Clique no **X** da aba.

<figure><img src="../../.gitbook/assets/0464.png" alt=""><figcaption><p>Fechando a aba “Bem-vindo”</p></figcaption></figure>

O editor fica assim:

<figure><img src="../../.gitbook/assets/0465.png" alt=""><figcaption><p>Editor sem a aba de boas-vindas</p></figcaption></figure>

{% hint style="info" %}
Se você quiser abrir essa aba novamente, use a Paleta de Comandos (`Ctrl + Shift + P` / `Command + Shift + P`) e procure por `Welcome`.
{% endhint %}
{% endstep %}

{% step %}
### 3. Abrir o Explorer (barra lateral)

Clique no ícone de **arquivos/documentos** (Explorer).

<figure><img src="../../.gitbook/assets/0466.png" alt=""><figcaption><p>Abrindo o Explorer</p></figcaption></figure>

Você verá a barra lateral:

<figure><img src="../../.gitbook/assets/0467.png" alt=""><figcaption><p>Explorer aberto</p></figcaption></figure>
{% endstep %}

{% step %}
### 4. Clicar em “Abrir Pasta...”

Clique em **Abrir Pasta**.

<figure><img src="../../.gitbook/assets/0468.png" alt=""><figcaption><p>Botão “Abrir Pasta”</p></figcaption></figure>

{% hint style="info" %}
Uma pasta aberta no VS Code é o seu “projeto”.
{% endhint %}
{% endstep %}

{% step %}
### 5. Criar a pasta `meu-projeto`

Na janela de seleção, clique em **Nova pasta**.

<figure><img src="../../.gitbook/assets/0469.png" alt=""><figcaption><p>Criando nova pasta</p></figcaption></figure>

Digite `meu-projeto` e clique em **Criar**.

<figure><img src="../../.gitbook/assets/0470.png" alt=""><figcaption><p>Nomeando a pasta do projeto</p></figcaption></figure>
{% endstep %}

{% step %}
### 6. Selecionar a pasta e clicar em “Abrir”

Selecione `meu-projeto` e clique em **Abrir**.

<figure><img src="../../.gitbook/assets/0471.png" alt=""><figcaption><p>Abrindo a pasta do projeto</p></figcaption></figure>

O Explorer passa a mostrar o projeto:

<figure><img src="../../.gitbook/assets/0472.png" alt=""><figcaption><p>Pasta aberta como projeto</p></figcaption></figure>
{% endstep %}

{% step %}
### 7. Criar um novo arquivo

No Explorer, clique com o botão direito e escolha **Novo arquivo...**.

<figure><img src="../../.gitbook/assets/0473.png" alt=""><figcaption><p>Criando um novo arquivo</p></figcaption></figure>
{% endstep %}

{% step %}
### 8. Dar um nome para o arquivo

Digite o nome, neste caso `meu-arquivo.txt`, e pressione **Enter**.

<figure><img src="../../.gitbook/assets/0474.png" alt=""><figcaption><p>Nomeando o arquivo</p></figcaption></figure>

Depois de criado, ele aparece no Explorer:

<figure><img src="../../.gitbook/assets/0475.png" alt=""><figcaption><p>Arquivo criado</p></figcaption></figure>
{% endstep %}

{% step %}
### 9. Escrever e salvar

Clique no arquivo, escreva qualquer texto e salve.

<figure><img src="../../.gitbook/assets/0476.png" alt=""><figcaption><p>Editando o arquivo</p></figcaption></figure>

A bolinha ao lado do nome do arquivo indica que **ainda não está salvo**:

<figure><img src="../../.gitbook/assets/0477.png" alt=""><figcaption><p>Arquivo com alterações não salvas</p></figcaption></figure>

Para salvar:

* Menu **Arquivo** → **Salvar**
* Windows/Linux: `Ctrl + S`
* macOS: `Command + S`

Quando salva, a bolinha para a ser um **X**:

<figure><img src="../../.gitbook/assets/0478.png" alt=""><figcaption><p>Arquivo salvo</p></figcaption></figure>
{% endstep %}

{% step %}
### 10. Renomear

Clique com o botão direito e selecione **Renomear**.

<figure><img src="../../.gitbook/assets/0479.png" alt=""><figcaption><p>Renomear pelo menu</p></figcaption></figure>

Digite o novo nome, neste caso `meu-arquivo-novo.txt`, e pressione **Enter**.

<figure><img src="../../.gitbook/assets/0480.png" alt=""><figcaption><p>Digitando o novo nome</p></figcaption></figure>

Resultado:

<figure><img src="../../.gitbook/assets/0481.png" alt=""><figcaption><p>Arquivo renomeado</p></figcaption></figure>
{% endstep %}

{% step %}
### 11. Excluir

Clique com o botão direito e selecione **Excluir**.

<figure><img src="../../.gitbook/assets/0482.png" alt=""><figcaption><p>Excluindo um arquivo</p></figcaption></figure>

Resultado:

<figure><img src="../../.gitbook/assets/0483.png" alt=""><figcaption><p>Arquivo removido do projeto</p></figcaption></figure>

{% hint style="warning" %}
Em alguns sistemas, excluir pode ir para a lixeira. Em outros, pode remover direto.
{% endhint %}
{% endstep %}
{% endstepper %}

***

Você agora domina as interações fundamentais necessárias para trabalhar com um projeto no Visual Studio Code. Ao longo desta seção, foi possível abrir uma pasta, criar arquivos, editar conteúdos, salvar alterações, além de renomear e excluir elementos.

Com isso, concluímos o conjunto de ações necessárias para compreender a primeira etapa do processo de salvar no Git: a manipulação de arquivos.

<figure><img src="../../.gitbook/assets/0440.png" alt=""><figcaption></figcaption></figure>

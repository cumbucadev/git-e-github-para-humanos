# 6.2.2 Visual Studio Code

O **Visual Studio Code (VSCode)** é um dos editores de código mais populares e amplamente utilizados na indústria. Ele é gratuito, Open Source e desenvolvido pela Microsoft. Sua popularidade se deve à facilidade de uso, suporte a diversas linguagens de programação e uma grande quantidade de extensões que podem ser instaladas para adicionar mais funcionalidades.

### Instalação do VS Code

O processo de instalação segue etapas semelhantes em diferentes sistemas operacionais.

{% stepper %}
{% step %}
### 1. Baixar

Acesse o site oficial: [https://code.visualstudio.com/](https://code.visualstudio.com/).

Clique em **Download**.

Escolha o instalador do seu sistema:

* **Windows**: prefira **User Installer** se estiver em dúvida.
* **macOS**: baixe o arquivo `.dmg`.
* **Linux**: baixe `.deb` (Debian/Ubuntu) ou `.rpm` (Fedora/RHEL).
{% endstep %}

{% step %}
### 2. Instalar

{% tabs %}
{% tab title="Windows" %}
1. Abra o arquivo `.exe`.
2. Clique em **Avançar** até o final.
3. Marque **Add to PATH**.
4. Clique em **Instalar**.

{% hint style="info" %}
O **PATH** permite abrir o VS Code pelo terminal usando `code`.
{% endhint %}

Se travar em algum passo, siga este tutorial com imagens:\
[Como instalar e configurar o VS Code](https://hub.asimov.academy/blog/como-instalar-e-configurar-o-vscode/).
{% endtab %}

{% tab title="macOS" %}
1. Abra o arquivo `.dmg`.
2. Arraste o **Visual Studio Code** para **Aplicativos**.
3. Abra o app pela pasta **Aplicativos**.
{% endtab %}

{% tab title="Linux (Ubuntu/Debian)" %}
1. Abra o terminal.
2. Vá até a pasta do download.
3. Rode:

```sh
sudo dpkg -i code_*.deb
```

Se aparecer erro de dependências:

```sh
sudo apt-get install -f
```
{% endtab %}
{% endtabs %}
{% endstep %}

{% step %}
### 3. Abrir

Depois de instalar, abra o VS Code:

* **Windows**: menu Iniciar → **Visual Studio Code**
* **macOS**: Aplicativos → **Visual Studio Code**
* **Linux**: rode `code` no terminal
{% endstep %}
{% endstepper %}

### Como alterar o idioma para Português (Brasil)

{% stepper %}
{% step %}
### 1. Abrir a Paleta de Comandos

Abra o VS Code.

Depois clique em **View** → **Command Palette...**.
{% endstep %}

{% step %}
### 2. Escolher o idioma de exibição

Digite `Configure Display Language` e selecione a opção.
{% endstep %}

{% step %}
### 3. Instalar Português (Brasil)

Clique em **Install additional languages**.

Procure por `Português (Brasil)` e clique em **Install**.
{% endstep %}

{% step %}
### 4. Reiniciar

Reinicie o VS Code para aplicar a mudança.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Referência oficial: [VS Code Display Language](https://code.visualstudio.com/docs/getstarted/locales).
{% endhint %}
